# EV Charging Station Management System

## About the Project
The EV Charging Station Management System is a web-based DBMS project designed to help users explore charging stations and manage bookings and payments.

## Features
- View available charging stations
- Book charging sessions
- Manage customer information
- View booking dashboard
- Payment interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js and Express (if configured in the project)
- MySQL (if configured in the project)

## How to Run
1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Follow the backend setup instructions once added to this README.
